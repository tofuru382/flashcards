# 憲法フラッシュカード（公民）

授業ノート（17 大日本帝国憲法 / 18 日本国憲法・前文）から作った暗記用フラッシュカードです。

- 8単元・138枚（制定過程、特徴・政治機構、軍部の台頭、日本国憲法の制定、基本原理、改正・公共の福祉・義務・平等、前文の穴埋め、漢字の読み）
- カードをタップでめくり、「✕ 間違えた / △ まだ不安 / ○ 覚えた」で自己採点
- 覚えた・まだ・覚えた回数・間違えた回数はブラウザのクッキーに保存
- 「覚えてない」「間違えた」だけの出題、シャッフル、答え→問題の逆向き出題
- バックアップコードで別の端末へ記録を移せます

カードを追加・修正するときは `cards.js` を編集してください。
