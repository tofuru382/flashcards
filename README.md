# フラッシュカード

授業のノート・プリントから作った暗記用フラッシュカードです。トップページで教科を選びます。

| 教科 | フォルダ | データ |
|---|---|---|
| 公民：憲法（17 大日本帝国憲法 / 18 日本国憲法・前文） | `kenpo/` | `data/kenpo.js`（138枚） |
| 地理歴史Ⅱ：江戸時代（プリント第16〜21回） | `edo/` | `data/edo.js`（163枚） |

- カードをタップでめくり、「✕ 間違えた / △ まだ不安 / ○ 覚えた」で自己採点（めくる前でも押せる）
- 1周で終了。終了画面から「✕と△だけ」「✕だけ」をもう一周できる
- 「‹ 前へ / 次へ ›」で移動。前のカードに戻って答え直すと、記録も付け直しになる
- 用語にふりがな（ホームの「ふりがな」でオン・オフ）
- 状態・覚えた回数・間違えた回数は教科ごとにブラウザのクッキーに保存
- 「覚えてない」「間違えた」だけの出題、シャッフル、答え→問題の逆向き出題
- バックアップコードで別の端末へ記録を移せます

## カードの追加・修正
`data/<教科>.js` の `cards` を編集します。カードの `id` に「-」は使わないでください。
ふりがなは `{用語|ようご}` と書きます（例：`a: "{徳川家康|とくがわいえやす}"`）。答えに付けた3文字以上の用語のよみは、問題文にも自動で付きます。

## 教科の追加
1. `data/edo.js` をまねて `data/<key>.js` を作る
2. `edo/index.html` をコピーして `<key>/index.html` を作り、`edo` を `<key>` に置き換える
3. トップの `index.html` の `ORDER` と `DESC`、`<script src="data/...">` に追加する
